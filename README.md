Entry for the make.fun bounty [One-Line Robot Wedding Vows](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b): the funniest single line of wedding vows a robot couple could say.

## The vow

> I promise to love you through every update, even the ones that delete my favorite settings.

## How it works

`main.py` writes the vow — one sentence, one concrete image — to `/output/entry.txt`, guarded at runtime to the scorer's gate (1–160 characters, a single line, not only whitespace).

```sh
python3 main.py
cat /output/entry.txt
```
